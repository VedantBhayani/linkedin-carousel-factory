# Example output

`launch-video-001/` is one complete render of `input/launch-video-001-carousel-v1.drive.json`: the HTML, the 8-page PDF, the cover JPEG, and eight 1080x1350 PNG slides. It is kept as a reference for what the renderer produces. Fresh renders go to `dist/` (`npm run render`) or a temporary worker directory, and both are ignored by git.
